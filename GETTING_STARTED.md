# Getting Started

A quick start for the **CEO Career Design System** — an interactive 6-stage app that turns career ambition into a designed path.

**Repo:** https://github.com/ianbess10/ceo-career-design

## 1. Open the app

```bash
git clone https://github.com/ianbess10/ceo-career-design.git
cd ceo-career-design
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

Progress is stored in **this browser** — use the same device/browser to continue later.

## 2. First-visit onboarding

On first open you’ll see a short welcome modal:

- **Begin Stage 1** — start at Clarify Your North Star
- **Continue where I left off** — dismiss and keep your current stage

Reopen anytime with **How it works** in the top bar.

## 3. Work one stage at a time

Each stage has the same shape:

1. Read the **title + tagline**
2. Study the **framework diagram**
3. Complete the **4 actions** (check them off)
4. Capture **notes**
5. Use **Previous / Next** or the left stepper to move

**Tip:** Don’t rush Stage 1. A clear North Star makes every later stage sharper.

## 4. Track progress

- Top bar shows **overall %** across all 24 actions
- Stepper shows per-stage completion (`2/4`, ✓ when done)
- At **100%**, a completion prompt offers PDF/text export

## 5. Save, export, reset

| Action | What it does |
| --- | --- |
| Auto-save | Checks, notes, and current stage persist in localStorage |
| Export text / PDF | Downloads your Career Design Doc |
| Print | Browser print layout of the full doc |
| Reset stage | Clears checks + notes for the current stage only |
| Reset all | Clears everything and returns to Stage 1 |

## 6. Suggested first session (30–45 min)

1. Stage 1: draft a one-sentence vision + check off the 4 actions
2. Stage 2: rough Position Audit (skills ∩ experience ∩ market)
3. Export text so you have a snapshot outside the browser

Come back later for Stages 3–6 with more focus time.

## The six stages

1. **Clarify Your North Star** — direction & impact ambition
2. **Diagnose Your Position** — honest leverage-zone audit
3. **Choose Your Arena & Focus** — pick where you’ll win
4. **Build Unique Advantages** — human + AI + systems stack
5. **Execute, Deliver & Compound** — trust and opportunity loop
6. **Lead, Multiply & Create Legacy** — impact that multiplies

## Troubleshooting

- **Lost progress?** Same browser/profile required; private/incognito won’t keep data.
- **Storage warning banner?** Export before clearing site data.
- **Clean slate?** Use **Reset all**, or clear site data for the app origin.
